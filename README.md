# Vertex-learning-plataform

Vertex is an AI-powered learning platform with intelligent content search.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port Next.js prints if 3000 is busy).

- Design system showcase: [http://localhost:3000/design-system](http://localhost:3000/design-system)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Design system

Tokens live in `app/globals.css`. Shared UI is under `components/ui/`. Art direction is in `design.md`. Reference mocks are in `design/`.
